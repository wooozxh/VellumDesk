## 2. 两套浅色色板（都非纯白）

### A ·「暖纸」（推荐）

| 角色 | 深色（现状） | 浅色 A |
|---|---|---|
| 画布底 `--bg` | `#111111` | `#eeebe4` |
| 面板 `--bg-soft`（顶栏/左栏/弹窗） | `#1b1b1b` | `#f6f3ec` |
| 次级面 `--bg-mute`（输入框） | `#232323` | `#e8e4da` |
| 卡片 `--bg-card` | `#2c2c2c` | `#fbf9f4` |
| 悬停 `--bg-hover` | `#353535` | `#e2ddd1` |
| 边框 `--line` / `--line-soft` | `#3a3a3a` / `#2b2b2b` | `#d5cfc2` / `#e3ddd1` |
| 文字 `--text` / `-2` / `-3` | `#efefef` / `#b3b3b3` / `#7c7c7c` | `#2a2721` / `#57514a` / `#8a8377` |
| 主色 `--accent` | `#2680eb` | `#1a6fd4` |
| 语义 `--warn/ok/danger` | `#e68619` / `#2d9d78` / `#e34850` | `#a8630d` / `#1f7a5c` / `#bd2b33` |

要点：**层级靠纸的明暗**（画布最暗 → 面板 → 卡片最亮），不靠纯白高光；卡片 `#fbf9f4` 与纯白有 2% 差，
不刺眼但依然浮起来。强调色整体压深一档，深色主题那档蓝在浅底上会"发光"。

### B ·「冷雾」（备选）

中性偏冷：`#eef0f3` / `#f8fafb` / `#fdfefe`，主色 `#0f6fd8`。
更像 Adobe / macOS 浅色面板，工具感强；A 更像纸，安静。**我建议 A**，和产品"有纸感"的调性一致。

## 4. 真正的工作量不在变量，在 52 处硬编码

`main.css` 里还有 **52 处**直接写死的颜色，都是"深底假设"。要逐条过，分四类：

| 类别 | 例子 | 处理 |
|---|---|---|
| 阴影 / 遮罩 | `.mask` `rgba(0,0,0,.62)`、`.modal` 投影 | 浅色下改暖灰、降不透明度（已 mock） |
| 自绘控件 | `select` 的 `--sel-arrow` 描边 `#b3b3b3`、`color-scheme: dark`、滚动条滑块 `#4f4f4f` | 换成变量 + `light` |
| 彩色徽标 | `.tk-type.digital` 写死 `#57d4d4`；`.btn.primary` 的 `#fff` 白字 | 青/紫这类浅色在浅底上会"发光"，要压深；白字在深蓝上仍 OK，保留 |
| 占位封面 | `.gen-cover` 按 `#16181c` / `#0f1013` 混色 | 改成按纸底混（已 mock） |

**浅色下还要复查的 4 个具体点**（mock 时已看到）：

1. **行级"压暗"用 opacity** → 浅色下几乎看不见（工单表里「已驳回 / 历史单」整行就是这么淡掉的）。要改成"降一档文字色"而不是降透明度。
2. **`.tk-dim` / `--text-3`** 在浅底上对比度只有 ~4.5:1，小字号 10.5px 的路径/表头要单独验。
3. **原生控件**：`input[type=date]` 的日历图标、`<select>` 弹出层，靠 `color-scheme` 才跟着变 —— 全站逐个数一遍 `<input>` 类型。
4. **模板信息卡 / 官网截图**：卡面本身是浅色的（白卡 + 橙线），深色界面下是"卡片浮在暗背景"，浅色下会和背景融在一起 —— 需要给卡加一层极淡的描边或阴影。

## 5. 实现方案（等拍板后执行）

1. **作用域**：`html[data-theme='light'] { --...: ... }` 一份覆盖块，防污染。默认不写属性 = 深色（老用户零变化）。
2. **持久化**：写 `meta` 表 `ui_theme`（`dark|light`），启动时主进程随 `appInfo` 一起下发；切换走一个新 IPC `ui:setTheme`（立即写库，掉电不丢）。
3. **按钮**：`App.tsx` 顶栏最右加组件；文案进 `COPY`（`tools/copy-sheet` 流程），不硬编码。
4. **切换瞬间不要闪**：`<html>` 属性由主进程注入的初始值在首屏前设好，不要在 `useEffect` 里设（否则深→浅闪一下）。
5. **验收**：
   - typecheck 0 错 / accept 只增不减（新增：默认深色、切换写库、重启保持、无属性=深色）
   - 场景新增断言：切换后 `html[data-theme]` 正确、按钮 tooltip 正确、浅色下关键元素不透明（抽查 3 处）
   - 手册：界面截图要不要出两套（**待拍板**，建议手册只放深色 + 一句说明）
6. **版本号**：1.12.0（带新功能），不出包不发版，等验收。

## 7. 实施记录（2026-10-30）

**主题怎么落地**

| 环节 | 做法 | 文件 |
|---|---|---|
| 变量 | `html[data-theme='light'] { ... }` 一份覆盖块，**不写属性＝深色**（老用户零变化） | `src/renderer/src/assets/main.css` |
| 持久化 | `userData/ui-prefs.json`（**不进工作区库** —— 工作区可能在没插的移动硬盘上） | `src/main/uiPrefs.ts`（新） |
| 读写通道 | `ui:theme` / `ui:setTheme`（都加进 `NO_MIRROR_CHANNELS`，换主题不该触发插件镜像） | `src/main/ipc.ts` |
| 首帧不闪 | 主进程按主题给 `backgroundColor` + 把 `?theme=` 带进 URL；渲染层在 `render()` **之前**打到 `<html>` | `src/main/index.ts`、`src/renderer/src/theme.ts`（新）、`main.tsx`、`index.html` 无需改（CSP 禁内联） |
| 按钮 | 顶栏最右 30px 圆钮，`sun`/`moon` 两个新图标 | `App.tsx`、`Icon.tsx` |
| 文案 | `COPY.top.themeToLight / themeToDark`（说的是"点了会变成什么"） | `src/shared/copy.ts` |

**顺带返工：`gear` 图标**（用户报）—— 原来画的是「小圆 + 8 根细射线」，13px 下被当成**小太阳**
（工单工具条那个"报表同步设置"按钮就被认错）。已改成真齿形轮廓（6 齿 + 内孔），
`gear` 是全局共用，设置弹窗标题一起变好。

**浅色下逐项校过的 5 处**（都是"深底假设"，换变量换不到）：

1. `.tk-row.dim`（已驳回 / 已撤销整行）原来是 `opacity: .45` → 浅底上整行几乎消失。
   ⇒ 浅色下**不降透明度，只降文字色**（`--text-3`）。实测正常行文字亮度 39、压暗行 105（≈4.4:1）。
2. 浅色 `--text-3` 从 `#8a8377` 压到 `#6f685d`：原值在纸底上只有 ~2.9:1，13px 中文读着费劲。
3. `select / input / textarea` 的 `color-scheme` **必须单独覆盖**（元素选择器上写死 dark，继承不过去），
   否则浅色里下拉展开仍是深色列表。
4. 阴影 / 遮罩 / 滚动条滑块 / 下拉箭头（`--sel-arrow`）/ 占位封面混色 —— 全部按纸底重算。
5. `.tk-type.digital` 写死的青色 `#57d4d4` 压成墨青 `#0d6b6b`（浅底上原色发光）。

**测试**

- accept 新增 `[70]` 7 条：缺省深色 / 写入读回 / 非法值回落 / 文件损坏不抛 / 写非法值等价深色 / 不覆盖同文件其它键
- 新增界面场景 `theme`（14 条）：默认无属性、按钮尺寸、图标、tooltip 方向、点了变浅（变量+body 底色）、
