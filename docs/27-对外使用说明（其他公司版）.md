# 设计物料管理软件 · 使用说明（对外版）

> 本软件产品名为**「Vellum工作台」**（英文标识 **VellumDesk**，2026-10-05 前内部曾称「营销中心-素材库」），
> 对外也可称**「设计物料管理软件」**（以下简写「软件」）。
> 本文写给**其他公司**：先讲清楚它是什么、能做什么，再**如实交代哪些地方是为原公司定制的、换你们来用需要做什么适配**。
> 版本：v1.8.1 ｜ 更新：2026-10-04

---

## 0. 一句话介绍

一个给**设计团队**用的本地工具：把"项目 → 任务 → 稿 → 素材文件"四层结构管起来；**可选**接企业微信，做"工单派单 + 月底导出报表"。

- **素材管理**：完全离线、零依赖，装完就能用。
- **工单协同**：依赖企业微信（智能表格 + 审批流 + 扫码授权），属可选扩展。

---

## 1. 它能做什么（功能一览）

### 1.1 素材管理（通用，装完即用）

| 能力 | 说明 |
| --- | --- |
| 四层结构 | 项目 › 任务 › 版本（V1/V2…）› 素材文件，磁盘上就是对应的真实文件夹 |
| 多稿版本 | 一个任务可开多稿，改稿新建一稿、旧稿留底，一键回滚"当前稿" |
| 缩略图 | 图片 / 视频 / PSD / PSB / PDF 自动生成缩略图，大图不拖慢界面 |
| 标签筛选 | 两套自定义标签（物料类别 / 使用场景），按标签快速找文件 |
| 认领归位 | 散在工作区里的文件一键"认领"进目标任务 |
| 打包交付 | 按版本 / 分组勾选文件，一键打 zip，文件名模板可自定义 |
| 文件丢失追踪 | 文件被删 / 挪走后不消失，标「文件已丢失」并可批量重新定位 |

### 1.2 工单协同（可选，依赖企业微信）

| 能力 | 说明 |
| --- | --- |
| 工单同步 | 从企业微信「智能表格」拉工单，自动按"项目名对得上"建任务文件夹 |
| 指派设计师 | 有权限者在软件里指派并写回企微表，自动通知本人 |
| 导出报表 | 按起止日期把已完成的工单写进另一张「工单报表」智能表格 |

> **核心卖点**：素材管理**不联网也能用**，文件全部留在贵司自己的硬盘上，不上传任何云端。

---

## 2. 先了解一件事：它"本来为谁做的"

软件最初是为**一支"接单 → 设计 → 交付"的设计团队**（营销 / 物料设计方向）定制的。因此有几处是**按原公司的业务假设做的**，换一家公司时请对照第 3 节的清单逐项确认。

---

## 3. 换一家公司：哪些直接用、哪些要适配（重点）

| # | 模块 | 现状 | 换公司后 |
| --- | --- | --- | --- |
| 1 | 素材管理核心 | 通用逻辑，不绑定任何业务 | ✅ **直接用**，零改动 |
| 2 | 预置项目 | 软件首启预置了 6 个原公司的项目 | 🟨 软件里可删 / 改，换成贵司自己的项目 |
| 3 | 预置标签 | 预置了「物料类别 11 项」「使用场景 7 项」 | 🟨 软件里可增删改，换成贵司的维度 |
| 4 | 默认工作区路径 | 首选 `D:\vellum_workspace`，无 D 盘自动落到「文档」 | 🟨 可改；跨盘搬移软件会提示手动复制 |
| 5 | 工单表 | 依赖企业微信智能表格，**结构是原公司约定好的** | 🔴 需按贵司工单结构对接（见第 5 节） |
| 6 | 报表表 | 依赖另一张企微智能表格，**12 列固定模板** | 🔴 需按贵司报表口径对接（见第 5 节） |
| 7 | 工单自动建任务 | 靠「业务归属」字段 == 软件里的项目名 | 🟨 规则可沿用，但要保证两边项目名一致 |

**结论**：贵司**只想要素材管理**，装上就能用，改改项目和标签即可；**要接工单**，则第 5、6 两项需要一次开发适配（字段映射），素材管理部分不受影响。

## 4. 素材管理：怎么用（简化上手）

### 4.1 先记住三层铁律

1. **本地磁盘是唯一真相，软件只是"镜子"**——文件在资源管理器里，软件扫描后如实反映。
2. **"任务"就是磁盘上的一个文件夹**——改名 = 文件夹改名，搬项目 = 文件夹搬家。
3. **软件不会自动发现新文件**——放完文件，回软件点一次「刷新/扫描」。

### 4.2 上手五步

1. **确认工作区位置**（左栏「工作区」，默认 `D:\vellum_workspace`，可改）。
2. **删掉预置项目、建自己的项目**（左栏「项目」区，＋ 新建 / 行上 ✎ 改名 / 🗑 删除）。
3. **整理标签**（左栏「筛选标签」→「管理」，换成贵司的物料类别与使用场景）。
4. **建第一个任务**（右上角「＋ 新建任务」→ 填名称 / 选项目 / 点类别）——磁盘上当场长出 `任务\V1\01-成品 02-素材 03-工程`。
5. **放文件 → 刷新扫描**：成品放 `01-成品`、原始素材放 `02-素材`、PSD/AI 源文件放 `03-工程`，回软件点「刷新/扫描」。

之后随时可「打包交付」生成 zip 发给客户 / 同事。

> 完整界面逐块说明见内部手册（本文聚焦"换公司"视角，不再逐按钮重复）。

## 5. 工单协同：依赖什么、结构约定是什么

> 🟥 **这一块是本文最重要的提醒**：工单 / 报表目前是**按原公司的企业微信表格结构实现的**，不是"任意表格都能接"。贵司若要启用，请先核对下面约定是否一致，不一致则需一次开发适配。

### 5.1 依赖前提

- 使用**企业微信**，并在企微里用「智能表格」管工单；
- 软件内置企微组件（wecom-cli），使用者**扫码授权一次**（以个人身份读表）；
- 工单走**企微审批流**（审批通过 / 驳回时，由审批流自动写入「完成时间」）。

### 5.2 工单表的约定（软件硬依赖的字段）

软件需要一张「工单队列」智能表格，且：

| 项 | 约定 |
| --- | --- |
| 子表 | 至少两个子表，软件里分别标「印刷 / 电子」 |
| 成员列 | 必须有「设计师」成员列（判断归属 + 指派写回） |
| 图片列 | 建议有「缩略图」图片列（完成任务时写回成品图） |
| 关键字段 | 编号、物料名称、申请人、申请部门、业务归属、设计师、交稿日期、提交时间、完成时间、物料申请用途、备注 |
| 印刷单另需 | 尺寸、印制数量、物料形态、物料类别、收货人、收货电话、送达日期 |
| 电子单另需 | 物料使用场景、物料类别 |
| 自动建任务 | 依赖「业务归属」字段与软件里项目名**完全一致** |

### 5.3 报表表的约定（12 列固定模板）

导出报表不是导出本地文件，而是写进另一张企微智能表格「工单报表」里的一个子表（子表名 = 起止日期）。该表需有一个 **「报表模板」子表**，列名与类型如下：

| # | 列 | 类型 |
| --- | --- | --- |
| 1 | 工单类型（印刷/电子） | 单选（印刷 / 电子） |
| 2 | 编号 | 文本 |
| 3 | 完成时间 | 日期 |
| 4 | 物料名称 | 文本 |
| 5 | 业务归属 | 文本 |
| 6 | 申请人 | 成员（多选） |
| 7 | 设计师 | 成员（多选） |
| 8 | 缩略图 | 图片 |
| 9 | 印刷数量 | 数字（整数） |
| 10 | 印刷金额 | 货币 |
| 11 | 绩效金额 | 货币 |
| 12 | 备注 | 文本 |

> 其中「印刷金额 / 绩效金额 / 备注」三个是软件**本地字段**（企微表里没有），由设计人员在软件里按单填写后随报表带出。

### 5.4 换公司后怎么对接

1. **工单结构一样 / 接近** → 几乎可直接用，最多对齐字段名与子表划分。
2. **工单结构不同**（字段名、子表划分、是否用企微都不一样）→ 需要一次开发适配：把软件的字段映射 / 列名 / 子表类型改成贵司的。**这是一次小改造，不是配置**。
3. **贵司不用企业微信** → 工单 / 报表模块无法启用；素材管理仍可正常使用。

## 6. 边界与已知限制（诚实交代）

| 项 | 现状 |
| --- | --- |
| 系统 | 仅 Windows 10 / 11（64 位），暂无 macOS / Linux 版 |
| 部署 | 单机本地软件，非 Web / 非 SaaS；一人一工作区 |
| 安装包 | 未购买代码签名证书，首次安装会有「Windows 已保护你的电脑」提示，需点「仍要运行」 |
| 联网 | 素材管理完全离线；仅工单同步 / 指派 / 导出报表需要能访问企业微信 |
| 删除 | 软件无"删除素材"按钮，删文件请走资源管理器（刻意设计，防误删） |
| 多机共享 | 一个工作区同一时间只在一台机器上用，不建议放网盘 / OneDrive 同步目录 |

---

## 7. 落地前，请贵司先确认这份清单

1. 是否**只用于素材管理**？→ 是：无需任何开发，改项目 / 标签即可上线试用。
2. 是否**要接工单**？→ 请提供贵司的工单表结构（字段 / 子表 / 是否走企微审批），我们评估适配工作量。
3. 是否**要导出报表**？→ 请提供贵司报表要统计的字段口径，我们据此改「报表模板」。
4. 工作区放**哪个盘 / 是否用移动硬盘**？
5. 团队多少人、是否**每人独立工作区**（当前不支持多人同时写同一个工作区）。

---

## 8. 结语

- **想快速试**：装好 → 删掉预置项目 → 建自己的项目与任务 → 放文件刷新扫描，半天即可验证素材管理是否合用。
- **想接工单**：先按第 7 节把工单结构发来，我们确认适配范围后再动工（**素材管理部分随时可先上线**）。

*（本软件一切操作以"本地磁盘是唯一真相"为前提。任何"不确定要不要删"的时候，先备份，再动手。）*
