# 界面层级归属规则（UI 优化的地基）

> 目的：回答"这个按钮到底该放哪"。**样式可以后调，位置错了怎么调都别扭。**
> 日期：2026-10-30　｜　配套原型：`docs/57-UI原型-v2.html`

---

## 一、四层模型

一个动作属于哪一层，由**它的作用域**决定，不由它的重要性决定。

| 层 | 作用域 | 载体 | 判断问句 |
|---|---|---|---|
| **L0 全局** | 整个应用、跨视图跨项目 | 顶栏左（品牌/搜索）、顶栏右（状态/设置）、状态栏（工作区/版本） | 「换个视图它还有意义吗？」有 → L0 |
| **L1 视图** | 只在当前视图内有效 | 视图工具条（内容区顶部那条） | 「切到别的视图它还在吗？」不在 → L1 |
| **L2 集合** | 对"当前选中的多个对象" | 底部悬浮批量条（选中才出现） | 「不选东西时它该亮着吗？」不该 → L2 |
| **L3 单项** | 只对某一行/某一张卡 | 行内悬浮 `⋯`、右键菜单、详情弹窗底部操作栏 | 「它只对这一个对象有意义吗？」是 → L3 |

**一条硬规则**：**同一层的动作只用一种载体**。不允许"顶栏有一个、工具条又有一个"（现在视图切换就是两处）。

## 二、逐项裁决（现状 → 结论）

### 2.1 现在放在顶栏、但不该在那儿的

| 动作 | 现状位置 | 真实作用域 | 结论 |
|---|---|---|---|
| 新建任务 | 顶栏，实心主按钮 | 只对任务视图成立（文件视图/工单视图里它没意义） | **降 L1** → 任务视图工具条右端 |
| 批量打包（n）/ 批量设置 / 取消 | 顶栏中间，选中时出现 | 对"选中的 N 个任务" | **降 L2** → 底部悬浮批量条 |
| 备份打包（进入备份模式） | 顶栏 | 是"任务视图"的一种模式，不是全局 | **降 L1** → 任务视图工具条的「视图模式」里 |
| 插件联动 | 顶栏常驻按钮 | 一次性配置项，配完一年不点第二次 | **降 L0 设置** → 设置弹窗「PS 插件」页；顶栏只留**状态指示**（连上/未连） |
| 刷新扫描（百分比） | 顶栏 | 扫的是整个工作区，任何视图都要用 | **保留 L0**，但改成图标钮 + 进度环，不占文字宽度 |
| 视图页签（5 个） | 顶栏中部 | 导航 | **保留 L0**（导航属于骨架），但收敛成 Segmented，不再与按钮同款 |
| 搜索框（placeholder 随视图变） | 顶栏 | 一个输入框承担两种语义：全库搜 / 当前列表筛 | **拆开**：顶栏＝全局搜索（Ctrl K，跨类型）；视图工具条＝本视图筛选 |
| 主题切换 | 顶栏 | 全局偏好 | **保留 L0**，但与设置同组（都属"偏好"） |

### 2.2 现在散在视图里、但该提到全局的

| 动作 | 现状 | 问题 | 结论 |
|---|---|---|---|
| 企业微信授权 | 工单视图内 / 首次向导 | 授权是**账号级**状态，工单视图只是它的消费者 | 提到 L0 设置「企业微信」，工单视图只在未授权时显示一条可点提示 |
| 工单同步设置（选子表/字段映射） | 工单视图工具条的齿轮 + 首次向导 | 配置项，不是日常动作 | 提到 L0 设置，工单视图保留"设置未完成"的状态提示 |
| 工作区路径 / 切换 | 左栏底部卡片 | 跨视图 | 保留在左栏底部（位置合理），但**状态栏同步显示**，避免两处信息不一致 |

### 2.3 现在混在两个层里、要分开的

| 动作 | 现状 | 结论 |
|---|---|---|
| 导出报表 / 同步工单 | 与视图筛选胶囊排在同一行 | **都是 L1**，但归到工具条右侧「操作区」，与筛选分开 |
| 扫描磁盘 / 重建卡片 / 导入 PSD / 新建分组 | 四个按钮平铺 | 导入 PSD＝L1 主操作（实心）；其余三个是维护动作 → 收进「维护」下拉，减少一排按钮 |
| 文件行里的 ×（删标签） | 常驻显示 | **L3**，只在行悬浮时出现 |
| 任务卡片的操作 | 卡片上无操作，全靠点开弹窗 | 补 L3：悬浮 `⋯`（打开文件夹 / 移动 / 删除） |

## 三、落到界面上的样子

```
┌───────────────────────────────────────────────────────────────┐
│ ◆ 工作台    [Ctrl K 全局搜索]     任务·工单·文件·模板    ⟳  ☾  ⚙ │  L0
├──────────┬────────────────────────────────────────────────────┤
│ 左栏      │ 任务视图  6 个 · 3 个待指派      [筛][排][密] ＋新建 │  L1
│ 标签树    ├────────────────────────────────────────────────────┤
│ 项目      │                                                    │
│          │   卡片 / 表格 / 列表                                │
│          │                                                    │
│          │  ┌──────────────────────────────────────────────┐  │
│          │  │ 已选 3 项   批量打包  批量改归属  打标签  ✕  │  │  L2
│          │  └──────────────────────────────────────────────┘  │
├──────────┴────────────────────────────────────────────────────┤
│ 筛选：全部 · 工作区 D:\...\shot_ws · 共 6 个任务 · v1.13.0      │  L0
└───────────────────────────────────────────────────────────────┘
```

- **L0 区**：高度固定 44px，只放"换个视图也还在"的东西。右侧三个图标钮（刷新 / 主题 / 设置）同一尺寸。
- **L1 区**：内容区顶部 48px，左标题、右工具，**主操作永远在最右**，且同屏只有一个实心按钮。
- **L2 区**：底部悬浮，圆角 + 阴影，出现时有 120ms 上滑，**不挤压内容**。
- **L3 区**：行/卡悬浮才出现，`⋯` 菜单，不做成常驻按钮。

## 四、这轮原型要验的 7 个判断题

1. 「新建任务」在文件视图里消失了 —— 会不会有人找不到？（备选：Ctrl N 全局可用 + 顶栏不放入口）
2. 「插件联动」进了设置 —— 新人第一次找得到吗？（备选：顶栏留一个"未连接"的角标提示）
3. 批量条挪到底部 —— 与状态栏叠在一起会不会太挤？
4. 全局搜索（Ctrl K）与视图内筛选分开 —— 两个入口会不会更乱？
5. 顶栏去掉文字按钮、只留图标 —— 认得出吗？
6. 「备份打包」收进视图模式的「⋯」—— 用的人多吗？藏了会不会被投诉？
7. 设置弹窗分 5 页（通用 / 工作区 / 企业微信 / PS 插件 / 关于）—— 够不够？

> 这 7 条我都在原型里做了可点的对应位置，看完直接说编号。

## 五、原型怎么用（`docs/57-UI原型-v2.html`）

单文件，双击打开。**不用装环境、不用起服务。**

| 操作 | 效果 |
|---|---|
| 顶栏中部 5 个页签 | 切 任务 / 工单 / 文件 / 模板 / 通用库 |
| 顶栏右侧「层叠」图标 | **打开层级视图**：把 L0 / L1 / L2 / L3 用彩色虚线框标出来，整体下移 20px 让标签浮在框外，不遮内容 |
| 顶栏右侧 ☀ / ☾ | 切深 / 浅两色（与产品那颗按钮同一逻辑） |
| 点卡片 / 文件行左边的方框 | **选中后底部浮出批量条**（L2 就在这一刻出现） |
| 右上角「改动清单」 | 打开右抽屉，列本屏改了哪几处，编号与本文件对应 |
| 顶栏齿轮 | 打开设置弹窗（看全局配置的收口方式） |
| Esc | 关弹窗 / 关抽屉 |

**这一版跟上一版原型的区别**（上一版只解决了"好不好看"）：

- 上一版把「新建任务」从顶栏挪到工具条，但**没解释为什么**，也没处理"文件视图里它变成什么"——这一版每个视图的主操作都不同（新建任务 / 导入文件 / 导入 PSD / 导入素材），同一坑位、动作随视图换。
- 上一版顶栏还留着"插件联动"按钮——那是配置项不是常用动作，这一版收进设置，顶栏只保留**状态**。
- 上一版批量操作条只在任务视图演示——这一版它是**同一套 L2 组件**，任务视图说"打包交付 / 改归属 / 打标签"，文件视图自动变成"移动到分组 / 打标签"。
- 上一版设置是散落的弹窗——这一版合并成一个 **5 页设置**（通用 / 工作区 / 企业微信 / PS 插件 / 关于），回答"全局功能放哪"。

**原型的精度**：1360×880 真实窗口、真实数据（项目名 / 工单编号 / 模板参数都取自现网截图）、
封面是按设计稿画的 SVG（不是纯色块）、卡片高度与行高都是最终值。
