Vellum工作台 v1.13.0 更新了，装之前看这几行就够：

【主要变化】
1. 界面统一了视觉规范（颜色、圆角、间距、表格密度），以前同一个软件里并存三套按钮高度、四种标签样式，现在收敛成一套。功能没变，只是看着对齐了。
2. 顶栏新增齿轮「设置」：插件联动、企业微信授权、工单同步配置都收进去了，改了就生效、没有保存按钮。顶栏原来那个「插件」按钮已经没了，去齿轮里找。
3. 顶栏最右可切换浅色 / 深色主题，切完会记住。深色仍是默认，习惯深色的不用管。

【位置调整】
· 「新建任务 / 备份打包 / 卡片·列表切换」从顶栏下移到任务视图顶上的工具条
· 左栏可以整栏收起（顶栏最左那个按钮），再点恢复
· 工单队列 / 模板 / 通用库这三个视图，那个位置显示软件 logo
· 顶栏换视图时控件不再左右跳了

【修好的问题】
· 工单同步设置里那个按钮被顶到框外、旁边的来源被挤成一个字
· 设置弹窗内容一多，「保存 / 取消」就被挤出屏幕，现在固定在弹窗底部（导出报表、插件联动一起修了）
· 工单视图「导出报表」旁边那个像小太阳的按钮，其实是工单同步设置，图标已换成齿轮
· 从 Mac 拷过来的「._」开头文件、.DS_Store 不再进素材库，已混进去的这次扫描会清掉

【怎么装】
直接装 VellumDesk-1.13.0-Setup.exe，覆盖安装即可，先别卸载。
数据一点不动：素材、任务、工单、模板都在你原来的工作区里。
如果 Windows 提示「未知发布者」，点「更多信息 → 仍要运行」。

上次那个 v1.12.0 已经撤回，这一版已经包含它（浅色主题 + 四个修复），装这一版就全有了。
