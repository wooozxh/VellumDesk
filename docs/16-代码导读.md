## 2. 看代码的四个常识

1. **注释**：`//` 开头（或 `/* */` 包起来）的行是**写给人的话，机器不执行**。本项目的注释基本都是中文，专门解释"为什么这么做"。
2. **颜色**：VS Code 里灰色/绿色的是注释，其他颜色是代码。看不懂代码时，**只追着注释读，也能读懂一半**。
3. **`import`**：文件开头的 import 是"借工具"——从这里借个弹窗，从那里借个图标，不用细究。
4. **改坏了也不怕**：整个项目在 git 管理下，每一版都存了底。真要动手改，改之前说一声，我先把当前状态提交存档，随时能还原。

## 4. 这个项目的三层结构（一张图记住）

```
你在界面上看到的（按钮、列表、弹窗）
        ↕  ipc.ts 负责传话
软件真正干活的地方（扫描文件夹、读写数据库）
        ↕
两个"仓库"：硬盘上的文件夹 + SQLite 数据库文件
```

- `src/renderer/` = 你看到的（React 界面）
- `src/main/` = 干活的（Electron 主进程）
- `src/shared/` = 两边共用的（名词表 types.ts + 文案字典 copy.ts）
