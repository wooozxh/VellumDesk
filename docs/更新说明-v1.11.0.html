Vellum工作台 v1.11.0 更新说明

v1.10.0（2026-10-11） → v1.11.0（2026-10-17）

一句话：多了「模板库」，文件能看列表了，勾几条就能批量干活。

一、新增：PSD 模板库（顶栏第五格「模板」）

专门放参考线已经打好的 PSD 模板 —— 在 PS 插件的「新建稿」里选中它，直接开一张新稿。

它和通用库不一样的地方

通用库 模板库
收什么 各种素材 只收 PSD / PSB
体积上限 无 单个 ≤ 20 MB
门槛 能打开就行 必须读到画布尺寸（读不到就不收）
分组层数 5 层 5 层
卡片上写什么 画面缩略图 信息卡（见下）

被拒绝的文件会明确告诉你原因（非 PSD / 太大 / 读不到画布），而且文件不会被动——它还在你原来的文件夹里。

卡片上写的是什么（不是缩略图）

模板卡不显示画面，显示的是一张信息卡：

一张卡片从上到下是四块：

位置 内容 从哪来
顶部 Vellum 的 logo 固定
橙色横线 分隔 固定
大字 品类，比如「展架」 文件名里第一个 _ 之前
三行参数 尺寸 / 出血 / 色彩模式 前两个读 PSD 关键词，色彩模式读 PSD 头
底部橙条 装饰 固定

为什么不用画面：PSD 里自带的预览图只有 160 像素左右，放大就糊；而这些信息本来就该用文字说清楚。

「尺寸」和「出血」要自己写进 PSD（PSD 格式里没有这两个字段）。在 PSD 的关键词里写：

size:80cm×180cm
bleed:5mm

写完点一次「扫描磁盘」就生效。还能写 usage:室内、client:海南升学、tag:竖版、note:主推款 —— 这些会进鼠标悬停提示（详见手册 6.7）。

不写也能用，只是尺寸会按画布算（算出来是含出血的，会比成品大一圈）。

参考线角标

卡片右上角会显示这份模板打了几条参考线 —— 这是模板库存在的理由，一眼看出"这份到底有没有打好线"。

二、新增：卡片 / 列表双视图

任务、通用库、模板库、文件视图，右上角都能切换 卡片 / 列表。

  • 卡片：看图、看信息
  • 列表：一次看很多条，按列排序，适合"找某一版"

列表视图每行的左侧有勾选框。

三、新增：勾选后批量干活

在列表里勾几条，上方会冒出一条批量操作条：

按钮 做什么 磁盘上的文件
移动到分组 挪到另一个分组 跟着搬（不是复制）
复制到任务 复制一份进某个任务的 02-素材 库里那份不动
批量改名 按序号统一改名：易拉宝-01、易拉宝-02… 文件名真的改了
清除记录 从软件里去掉，不显示 一动不动，重新扫描就回来
删除 移走这个文件 移到 _回收站，能找回

「批量改名」会实时显示效果（易拉宝-01.psd），确认没问题再点执行。

任务视图还有两个：

  • 批量打包（n） —— 给勾中的任务各打一个备份 zip
  • 批量设置 —— 一次改勾中任务的「项目 / 类别 / 场景 / 分级」，只有你选了的项才会改

四、改进：模板缩略图不再糊

v1.10 之前，模板卡的缩略图是 PSD 内嵌的预览图（约 160 像素），放大后很糊。

现在：软件渲染一张 512×512 的信息卡图交给 PS 插件 —— 插件里看到的和软件里是同一张卡，字清得能读。

插件不用更新：镜像里的字段和路径完全没变，只是图的内容换了。

五、修复

  • 工单筛选的时序 bug：以前在「我的」下点「同步工单」，同步途中切到「全部」，同步完成后列表会显示成「我的」的内容、而标签还亮着「全部」，得再点一次才对。已修。

六、升级提示

  1. 首次打开会自动升级数据库（给模板表加两列），不用手动做什么，但别在升级中途强退。
  2. 模板库第一次进要扫一次：进模板库 → 点「扫描磁盘」。
  3. 插件侧：模板缩略图的内容换成了信息卡（512×512）。如果插件里的模板格子偏小（比如 120px 高），信息卡上的小字会糊 —— 建议格子至少 179×179。这条已经和插件侧对过，他们会调。

七、已知限制

项 说明
模板卡不显示画面 有意为之（画面缩略图只有 160px，且模板要的是参数不是画面）
PSD 关键词要手动写 PSD 里没有"成品尺寸/出血"的标准字段，只能靠关键词补
按关键词筛选模板 还没做 —— usage / client / tag 现在只进悬停提示，不能筛
从参考线自动推出血 没做（参考线也可能是栏间距，误判比不判更糟）
