# Vellum工作台 v1.12.0 更新说明

> 上一版：v1.11.0（2026-10-17）　→　本版：v1.12.0（2026-10-30）
>
> 一句话：**加了浅色界面（顶栏一键切），顺手修掉四个「用着别扭」的地方**。

---

## 一、新增：浅色主题

顶栏最右边多了一个圆钮，点一下就在**深色 / 浅色**之间切换。

| 按钮上画的 | 意思是 |
|---|---|
| ☀ 太阳 | 现在是深色，**点它变浅色** |
| ☾ 月亮 | 现在是浅色，**点它变深色** |

- **切完会记住**，下次打开还是那个模式。
- 浅色不是纯白：底是暖纸色（`#eeebe4`），面板和卡片一层比一层亮一点点，长时间看不刺眼。
- 功能完全一样，只是换了配色。深色仍是默认，习惯深色的同事不用管它。

> 为什么不是"跟随系统"：只有两个状态，自己点一次就定下来，不会出现"我明明选了浅色它又自己变回去"。

## 二、修：设置弹窗的「保存」按钮点不到

**现象**：首次配置引导里填完工单链接，或者打开「工单同步设置」，弹框里的说明文字一多，**保存 / 取消就被挤到屏幕外面**，只能按 Esc 关掉。

**现在**：弹框内容多的时候**自己滚动**，保存 / 取消**固定在弹框底部**，永远看得见、点得到。

同一个毛病一并修好的还有：**导出报表**、**插件联动设置**（这三处是同一套弹框）。

## 三、修：那个「小太阳」其实该是齿轮

工单队列里，「导出报表」旁边那个按钮（工单同步设置）原来的图标画得像颗太阳，十几个同事都以为是"主题切换"。已换成正经齿轮。

## 四、修：素材库里冒出 `._` 开头的怪文件

**现象**：从 Mac 拷过来的素材文件夹，素材墙里会多出一堆 `._IMG_0001.jpg`、`.DS_Store` 之类的条目，看着像素材、点开是坏的。

**原因**：macOS 把文件写到 exFAT / 网络盘时会自动配一个同名 `._xxx` 的附属文件（只装元数据，固定 4 KB），跟真素材没关系。

**现在**：

- 这类文件**不再进素材库**（扫描时直接跳过，磁盘上一个字节都不动）。
- 库里**已经混进去的**，这次扫描会自动清掉记录（同样不动磁盘文件）。
- 删组时如果目录里只剩这类文件，也能正常删掉了（以前会被它们挡住，删完下次扫描又冒出来）。

## 五、升级

| 项 | 说明 |
|---|---|
| 怎么升 | 下载 `VellumDesk-1.12.0-Setup.exe` 直接装，覆盖安装即可 |
| 数据 | **一点不动**。素材、任务、工单、模板都在你原来的工作区里 |
| 要注意 | 如果 Windows 提示"未知发布者"，点「更多信息 → 仍要运行」 |
| 手册 | 随包附 `Vellum工作台-用户手册-v1.12.0.html`（单文件，双击就能看），已补上主题切换的说明 |

## 六、已知限制

- 浅色模式下**手册截图仍是深色**（这次没重拍），看截图时留意一下配色差异。
- 主题是**每台机器各自记**的，不跟着工作区走 —— 换电脑 / 换工作区需要重新点一次。
- 老问题仍在：模板库不能按 usage / 客户 / 标签筛选；导出 PNG 尚未支持。
