# 第 11 批 · UI 改版方案（对齐 Adobe Spectrum 2）

> 用户原话：「整个儿布局其实不需要变，我觉得还不错。但是整个 UI 的配色、按钮 icon 的样式我想都调整一下儿，然后整个儿参考 adobe 软件儿的通用的 UI 的比较新的样式就可以。然后看看，先看看能做成什么样儿，然后我们再调细节。」

---

## §0 一句话

**布局一格不动，只换皮**：灰阶从"偏蓝冷黑"换成 Adobe Spectrum 2 的**无彩中性灰**，强调色换成 Adobe 蓝，按钮/输入框/标签改**胶囊形**，12 处 emoji 图标换成**手写线性 SVG**，并补上键盘焦点环。

---

## §1 为什么是这几件事

### 1.1 根子问题：现在的深色"偏蓝"

原色板每一档都掺了蓝：

| | 原值 | 色彩倾向 |
|---|---|---|
| `--bg` | `#15161a` | R21 G22 B26 → 蓝比红多 5 |
| `--bg-soft` | `#1b1d22` | 蓝比红多 7 |
| `--bg-mute` | `#212429` | 蓝比红多 8 |
| `--bg-card` | `#1e2127` | 蓝比红多 9 |

Adobe Spectrum 2 的灰阶是**纯中性**（R=G=B），一个字节的色偏都没有。这是"看着像不像 Adobe"最根本的一条 —— 比换什么强调色都重要。

### 1.2 第二个问题：图标是 emoji

软件里 12 处图标全是 emoji（📥📁🔍📎✎🗂📦🏷⚠），在 Windows 上由 `Segoe UI Emoji` 渲染成**彩色字体图标**：颜色固定、跟文字不同色、粗细不可控、跟界面完全不是一个血统。

专业软件（Adobe / Figma / Blender）的图标都是**同色线性图标**：跟文字同色、1.5px 描边、圆头端点、可随状态变色（悬停变亮、危险变红）。

### 1.3 第三个问题：方角 + 没有焦点环

- 按钮 6px 方角、输入框 6px 方角 —— 而 Spectrum 2 最显眼的外观特征就是**胶囊形**
- 全软件没有键盘焦点环 —— Tab 键走位时看不出焦点在哪，更没有 Adobe 那种「2px 蓝圈 + 2px 间隙」的标志性细节

## §4 图标：emoji → 线性 SVG

新建 `src/renderer/src/components/Icon.tsx`，27 个图标，零依赖，统一规范：

- 24×24 网格，只描边不填充，笔宽 **1.6**（16px 下最接近 Adobe 观感），圆头 + 圆角端点
- `stroke="currentColor"` → 图标跟文字同色，hover / 选中 / 危险态自动跟着变
- API：`<Icon name="search" size={13} strokeWidth={2} />`

| 图标 | 替换掉 | 用在哪 |
|---|---|---|
| `search` / `locate` | 🔍（两种语义原来共用一个） | 搜索框、丢文件重新定位 |
| `refresh` | 🔄 | 刷新扫描 |
| `edit` / `trash` | ✎ / ✕ | 编辑、删除（原来"删除"和"关闭"都用 ✕，语义混） |
| `close` / `check` / `plus` | ✕ / ✓ / ＋ | 关闭、保存、新增 |
| `inbox` / `export` | 📥 / 📤 | 认领入库 / 解绑移出 |
| `folder` / `archive` / `package` | 📁 / 🗂 / 📦 | 包 / 归档 / 无封面占位 |
| `tag` / `clip` | 🏷 / 📎 | 标签 / 绑定文件夹 |
| `warning` | ⚠ | 文件丢失（原来用 emoji ⚠️，还带着变体选择符） |
| `caret` / `caretDown` / `star` / `bulb` | ▸ / ★ / 💡 | 折叠、星标、建议提示 |
| `arrowUp` / `arrowDown` | ↑ / ↓ | 项目上移下移 |
| `image` / `play` / `external` / `filter` / `layers` | — | 备用 |

**顺带修正的语义混用**：原来「删除项目」（App.tsx）、「删除标签」（TagManagerModal）都用 `✕`，跟"关闭弹窗"一模一样。现在删除统一用 `trash`，关闭统一用 `close`。

## §5 控件形态

### 5.1 胶囊

| 元素 | 原 | 新 |
|---|---|---|
| `.btn` / `.tabs` / `.tabs button` | 6px / 4px | 999px |
| `.search-wrap input` | 6px | 999px |
| `.field input` / `.field select` | 6px | 999px |
| `.chip` | 20px | 999px |
| `.tag` / `.row-tag` / `.role` / `.miss-badge` / `.miss-flag` / `.ver-badge` | 3~20px | 999px |
| `.icon-btn` / `.mini` / `.modal .close` / `.swatch` / `.tm-color` | 4px | 50%（圆形） |

**没改的**：卡片、弹窗、列表行、面板、缩略图格子 —— 这些是"容器"不是"控件"，保持方角（8~10px）。Adobe 也是这个规矩。

### 5.2 按钮四态

```css
.btn                透明底 + 1px #3a3a3a 边 + 次要文字色
.btn:hover          填充 #353535 + 文字变亮 + 边框变亮
.btn.primary        实心 Adobe 蓝 + 白字
.btn.primary:hover  实心变亮（#378ef0）
```

原来是"浅底 + 描边"（`background: var(--bg-mute)`），改成"透明 + 描边"，让主按钮在视觉上真正跳出来。

### 5.3 键盘焦点环

```css
:focus-visible { outline: 2px solid var(--accent-hover); outline-offset: 2px; }
```

覆盖 24 类可交互元素（按钮、链接、标签、卡片、版本格、列表项…）。用 `:focus-visible` 而不是 `:focus`，**鼠标点击不显示、只有键盘 Tab 走位才出现** —— Adobe 的标准做法，不打扰鼠标用户。

输入类（搜索框 / 弹窗输入框）不叠外圈，因为 focus 时边框本来就变蓝了。

### 5.4 分段控件（视图切换）

「包视图 / 文件视图」原来是两个方角按钮拼一起，改成 Spectrum 的 segmented control：**凹槽（`--bg-mute` + 胶囊）+ 浮起的药丸（`--bg-hover`）**。

## §8 施工中发现

### 8.1 `--text-1` 是个不存在的变量（6 处）

`main.css` 里有 6 处写的是 `color: var(--text-1)`，但 `:root` 里**从来没有定义过 `--text-1`**（只有 `--text` / `--text-2` / `--text-3`）。

后果：这 6 个元素一直在靠**继承父级颜色**凑合，颜色碰巧看着对，但一旦父级颜色变了就会跟着漂。第 9 批做版本条时留下的。本次一并修成 `var(--text)`。

**教训**：CSS 变量名写错**不会报错也不会告警**，只会静默失效。这类笔误只能靠"把所有 `var(--x)` 和 `:root` 定义对一遍"来抓 —— 已记进 NEXT 的环境坑速查。

### 8.2 改造手段：脚本 + 断言

CSS 2273 行、15 个组件近百处图标，逐处手改容易漏也容易错位。本次用三个一次性 Python 补丁脚本（`_ui_patch.py` / `_app_patch.py` / `_comp_patch.py`）：

- 每处替换都带**数量断言**（期望几处就写几处），对不上就整体中止、不写文件
- 靠"选择器块正则"而不是行号定位（行号会随前面的替换漂移）
- `--text-1` 那个笔误就是断言报"期望 1 处、实际 6 处"抓出来的

## §10 给下一批的话

1. **字重待统一**：项目里 `font-weight: 600` 用得不少，Adobe 体系只有 400 / 500。要统一的话建议单独一批做，别和别的改动混。
2. **状态色还可以再细分**：现在语义色只有 warn / ok / danger / purple 四支，Adobe 有 notice / negative / positive / informative / accent 各 16 档。目前够用。
3. **图标按需扩**：`Icon.tsx` 里已经留了 `image` / `play` / `filter` / `layers` 四个备用图标（M6-06 版本对比做图片并排、视频双窗时会用上）。
4. **浅色主题**：这次只做深色（软件本来就是深色）。Spectrum 2 的浅色令牌是完整一套，将来要做的话，因为这次已经把颜色全收归变量了，加一套 `[data-theme='light']` 覆盖即可。
