PART ONE

第一部分 · 认识它

先花十分钟把「这个软件到底在解决什么问题」「里面的名词是什么意思」搞清楚。这一部分不涉及操作，但看懂了后面会顺很多。

1.1这个软件是干什么的

一句话：把公司散在各人电脑里的设计物料，收进一个统一的、有规矩的工作台。

它要解决的是四个老毛病：

找不到
文件散在桌面、微信、下载文件夹里，改完的那版到底在哪只有本人知道。
没分类
同一个海报改到第五版，靠文件名里的「最终」「最终2」「真最终」区分。
交付靠手工
给同事发物料，每次都要现挑文件、现命名、现压缩。
和工单对不上
企微上派下来的单，干了没干、交了什么，月底靠翻聊天记录对。

它不做什么（很重要）

  • 不做云端同步：素材只在你的硬盘上，软件不上传任何文件；
  • 不做在线协作：一个工作区同一时间只在一台电脑上用；
  • 不做在线编辑：改图改视频，还是用 Photoshop / Pr，软件只管「收、找、交」。
一句话记住这个软件的定位是「素材的仓库管理员」，不是「设计工具」。它管的是文件放在哪、属于哪个活儿、该交付给谁。

1.2三种人、三件事（典型一天）

同一套软件，三种人用法完全不同。先对号入座，再决定看哪一章。

A · 设计师（主要使用者）

  1. 打开软件 —— 默认就停在「工单队列」，先看有没有派给自己的新单。
  2. 发现有新单还没建任务 → 点 同步工单，软件自动把任务文件夹建好。
  3. 点开这条工单，看尺寸 / 数量 / 交期 / 参考附件（打开审批（含附件））。
  4. 去资源管理器（或直接在软件里）把源文件放进任务的 02-素材、03-工程。
  5. 回软件点 刷新/扫描；干完活把成品丢进 01-成品，再扫一次。
  6. 要改稿 → 任务详情里 ＋ 新建版本 建 V2，把新稿丢进去。
  7. 要交付 → 打包交付 生成 zip，发给申请人。
  8. 收工 → 完成任务，成品缩略图自动写回工单队列（供绩效与报表用）。

B · 组长 / 管理员

  1. 在左栏维护项目 —— 新业务立项、结项解绑。
  2. 看左栏 ⚠ 文件已丢失 入口 —— 是不是有人动了磁盘。
  3. 任务视图上扫一遍各任务的版本与交付状态。
  4. 工单队列看「未指派」→ 在工单详情里分派给设计师（自动通知本人）。
  5. 月底 → 工单队列 导出报表，按起止日期导出到「工单报表」。

C · 只是想找一张素材

  1. 文件视图 → 搜索框输关键词。
  2. 左栏点标签缩小范围（标签后面的数字就是命中条数）。
  3. 勾上 只看当前稿，排除历史稿的干扰。
  4. 找到后双击文件名，用系统默认程序打开；右键或行尾按钮「打开所在文件夹」。

1.4三条铁律

这三条是软件的设计底线。理解它们，你就知道哪些操作是安全的、哪些会踩坑。

铁律一 · 本地磁盘是唯一真相，软件只是「镜子」

软件不「拥有」文件 —— 文件在资源管理器里。你在资源管理器里删了 / 挪了，软件下次扫描时会如实反映（标「文件已丢失」或清理记录）。

好处
软件崩了、换电脑、重装，你的文件一个不少。
代价
绕过软件去动文件夹，会带来「记录对不上」的麻烦（见 6.4）。

铁律二 · 「任务」是文件夹，不是数据库里的虚拟对象

所以：改任务名 → 文件夹跟着改名（里面文件一个不动）；改所属项目 → 文件夹搬进另一个项目文件夹；磁盘上任务文件夹没了 → 刷新扫描后记录自动摘除（留痕在 _system\backup\）。

铁律三 · 工单只负责「起头」和「回写」，不负责搬文件

工单同步只会自动建一个空的任务文件夹，不会替你把文件放进去。设计师干的活（放文件、改稿、打包）都在任务这边；做完点「完成任务」，把成品缩略图写回工单队列。

注意软件里没有「删除素材 / 删除任务」按钮。想删文件请去资源管理器删，想删任务就删任务文件夹再刷新扫描 —— 这是刻意的，防误删。

1.5安装与第一次启动

你需要准备什么

项目要求说明

安装步骤（照着点）

  1. 把安装包存到电脑上（比如桌面），双击运行。
  2. 会弹出蓝色的「Windows 已保护你的电脑」—— 这是正常现象，因为安装包没有购买代码签名证书（企业内部软件常见）。点 「更多信息」→「仍要运行」，不要点「不运行」。
  3. 选择安装位置。安装向导会让你选目录，默认是 C:\Program Files 下的系统目录 —— 建议改成非系统盘，例如 D:\软件\Vellum工作台。这个目录只放软件本身，和素材工作区是两回事。
  4. 一路「下一步」→「安装」→ 等进度条走完 →「完成」（可以勾选直接启动）。
  5. 安装完成后：开始菜单会出现「Vellum工作台」；桌面可能也有快捷方式。卸载走「控制面板 → 程序和功能 → Vellum工作台」。

1.6备份 / 换电脑 / 卸载

备份 = 复制一个文件夹

整个工作区文件夹拷走，就是完整备份（素材 + 数据库 + 标签 + 版本记录 + 工单记录全在里面）。

想做什么怎么做
日常备份定期把 D:\vellum_workspace 复制到移动硬盘或另一台机器（资源管理器复制粘贴即可）
换电脑① 新电脑装好软件；② 把工作区文件夹拷过去（盘符路径尽量一致）；③ 打开软件 → 左栏「＋ 添加工作区」→ 选那个文件夹 → 软件自动把库里的路径改成新位置（改前自动备份到 _system\backup\）
换盘同盘内搬家：左栏「搬移位置」；跨盘：资源管理器复制整个文件夹 → 「＋ 添加工作区」指过去 → 确认无误后再删原位置
一个软件管多个库左栏「＋ 添加工作区」可以加多个（比如「2026 年素材」和「历史素材」），点一下即可切换

卸载

控制面板 → 程序和功能 → 卸载「Vellum工作台」。

卸载不会删你的素材工作区文件夹、你的设计文件、数据库都留在原处。想彻底清干净，卸载后再手动删 D:\vellum_workspace（删之前务必确认已经备份）。
PART TWO · 模块一

工单队列

顶栏第一格，也是软件启动后默认停留的地方。它把企业微信「智能表格」里的审批单同步进来，让你在软件里接单、指派、建任务、导报表。这一整章的数据都来自企微表格，软件本身不产生工单。

这一屏就三块：左边一列筛选，右上角一排按钮，下面是工单列表。

第一次用会看到什么如果这台电脑还没授权企业微信，进这一格会直接弹出扫码引导（见 2.6）；如果授权了但还没配表格，会提示「工单功能未配置：点这里粘贴智能表格链接」。

2.2七个筛选

点一下切换，列表跟着变。顶栏「工单队列」按钮上那个数字角标，口径就是「未指派」。

未指派设计师列为空的单（顶栏角标数字就是这个口径）

允许在本机指派设计师开启后才能在工单详情里指派并写回企微表（需要表格可编辑权限）。改动立即生效，不用点保存
自动同步见 2.8
危险操作 · 清理这些工单清理已关闭子表残留的本地工单，见 6.4 第 6 条
首次同步的后果，弹窗里会明说「首次同步会把当前表里所有工单标记为历史单，不建任何任务」—— 也就是说，第一次点「同步工单」不会突然给你长出几百个任务文件夹。这是刻意的。之后新出现、且设计师列里有你的单，才会自动建任务。

2.6连接企业微信（扫码授权）

工单数据从企业微信「智能表格」来，软件要以你的身份去读它 —— 这一步就是把这台电脑绑到你本人。没做这一步，工单队列是空的。

三条路进得来

  • 装完第一次打开时自动弹一次（只在「组件在、但还没授权」时弹）；
  • 工单队列 → ⚙ → 最上面「企业微信连接」那一行的 打开连接引导；
  • 同步失败、提示授权过期时，软件会自动把它弹出来。

怎么做

  1. 先看第一行的状态徽标（见下表）。
  2. 点 开始扫码授权 → 窗口里出现一张二维码。
  3. 用手机企业微信扫它 → 手机上点「确认」。
  4. 窗口自动变成「已授权」，并显示你的名字 —— 这就是「连上了」最直接的证据。

扫码不方便？二维码旁边还给了一条授权链接，复制到手机上打开，同样能完成授权。

状态含义你要做什么
已授权一切就绪什么都不用做
未授权组件在，但没绑过企业微信点「开始扫码授权」→ 手机企业微信扫码
内置组件缺失安装包不完整换最新安装包重装一次（其他功能不受影响）
状态未知组件在但问不出状态（少见）点「重新检查」；还不行就重装
授权只需一次以后升级软件、重装软件都不用重扫（凭据存在 Windows 用户目录里，不在软件安装目录，软件自己也不存）。但换电脑、或换 Windows 登录账号要重新扫一次。
不要随便点「重新授权」它会让旧凭据作废，得从头再扫一遍。除非确实换了人、或授权已过期。

2.7指派设计师

组长 / 管理员用。把「未指派」的单分给具体的人，写回企微表并给对方发一条通知。

前置：先打开开关

工单同步设置里把 允许在本机指派设计师 打开（需要你在表里有可编辑权限）。没开的话，工单详情里只会显示「等待指派」。

操作三步

  1. 工单详情 → 指派设计师下拉，选人（每个候选后面标着「在办 N 单」，方便平衡工作量）。
  2. 选完变成标签，可以继续加人（多人协作单）。
  3. 点 提交指派 —— 这时才真正写回企微表，并给本人发通知。

三种失败提示

提示意思
已指派给某某，通知未送达表已改好，只是通知没发出去 —— 可在企微里直接转告
已指派给某某，写回表格失败下次同步会自动补写，也可在表格中手动改
表格里的「设计师」列不可用列缺失或被改名了，去表格里检查
三条限制 ① 至少保留一位设计师 —— 接口没法把成员列清空，要清空请去表格里手动清；
② 历史单 / 待确认单 / 已删除行的单不能指派；
③ 候选设计师为空时，先在表格里填一次设计师，软件会记住这些人。

2.8自动同步

不想每天手点「同步工单」，就在工单同步设置里打开自动同步。

项说明
每隔一段时间自动同步打开后：软件启动 15 秒先同步一次，之后按设定的间隔自动拉取
间隔单位分钟，可填 10 ~ 1440（最短 10 分钟，最长一整天）
上次同步显示上次成功 / 失败的时间；失败时可以点它跳到设置里排查
关掉就只能手动同步自动同步默认是开的。如果你在不稳定的网络下，可以关掉它，只在需要时手点 同步工单。

2.10同步流程与失败处理

一次「同步工单」在背后做了这些事。看懂这张图，你就知道为什么有的单自动建了任务、有的没有。

自动建任务的五个条件（缺一条就不建）

  1. 不是历史单（首次同步的存量单不建）；
  2. 不是待确认单（子表重建后的新单要先放行）；
  3. 本机使用者在该单的「设计师」列里；
  4. 审批状态是「就绪」（审批中 / 已通过这类）；
  5. 该单的「业务归属」能在软件里找到同名项目。
第 5 条最容易卡住表格里写「海南升学集训营」，软件里项目叫「海南升学集训营（2026）」→ 名字对不上 → 不建任务（会进「异常」筛选并给警告）。把项目名对齐，下一轮同步会自动补建。

三类失败的界面提示（都不会白屏、不会静默）

提示原因怎么办
企微同步暂不可用（内置组件缺失或未授权），其余功能不受影响安装包损坏 / 没授权界面会自动弹出授权引导，扫码一次即可；组件缺失则重装。素材管理功能不受影响
企微授权已过期，请在企业微信里重新授权后重试授权失效界面会自动弹出授权引导，重新扫一次
同步失败：<具体原因>其他（表格删了、字段被改名、网络等）按提示排查；字段类问题去表格核对列名

另外这些警告会出现在同步结果里：配置的子表找不到了（本次跳过）、检测到子表重建（新单标「待确认」）、记录没有审批编号（跳过）、审批单编号重复（两份都保留）、写回失败（下次自动重试）。

字段怎么填说明

名字会被自动净化非法符号 < > : " / \ | ? * 会变成 _；开头的 . 或 _ 会变成 -（下划线开头是软件的保留前缀）；结尾的点和空格会被去掉；重名会自动加 -2。所以不用担心起名起错，但起完可以去资源管理器核对一眼。

3.4编辑任务信息

两个入口：任务卡片右上角 ✎（悬停卡片才出现），或任务详情里的 ✎ 编辑任务信息。

改什么会发生什么
任务名称工作区里的任务文件夹会一起改名，里面的文件一个不动
所属项目任务文件夹会搬进对应的项目文件夹；选「不指定项目」则搬回工作区根目录（待归类）
类别 / 使用场景 / 分级只改数据库，磁盘上一个字节都不动
扫描临时文件勾选后，「刷新 / 扫描」会把本任务下的临时文件（~$ / ~S / *.tmp）也收进任务。默认不扫描 —— 这些多是软件生成的中间产物，扫进来很快会消失，会被误报「文件已丢失」
弹窗底部会预告后果改名 / 搬家时，底部会写「保存后文件夹会立刻改名 / 搬家（本地磁盘上的操作，不复制、不删除）」；只改类别时则写「磁盘上的文件夹一个字节都不动」。
别在资源管理器里手改任务文件夹那样做，刷新扫描后旧任务的记录、标签、版本关联会被清理（留痕在 _system\backup\），改名后的文件夹会变成「游离的包」出现在「待归类」里。

分组对应磁盘目录放什么

元素作用
V1 / V2 / … 格子点一下切换「看哪一稿」，下面的文件列表跟着变

＋ 新建版本建 V<下一号> 文件夹，里面自动长好三个空组

未分版本装着没进 V1/V2 文件夹的文件（老任务常见）

新建版本弹窗里的三个选项

选项什么时候用

3.8完成任务（缩略图写回工单）

用途：把最新版本里的全部成品图（有几张传几张）生成缩略图，逐张上传写回工单队列的「缩略图」列 —— 供绩效统计和导出报表取用。

结果提示

任务没关联工单该任务未关联工单

3.9快捷方式

任务在磁盘上是个文件夹。这个按钮让你不开软件也能直接进那个文件夹。

三步

  1. 任务详情 → 点 快捷方式。
  2. 桌面和开始菜单各出现一个图标 —— 以后双击就能进这个任务的文件夹。
  3. 完成时给一条提示：「快捷方式已建好：桌面 + 开始菜单（任务名）」。

三种边界情况

情况行为

4.5批量打标签

文件视图勾选文件 → 认领条上点 🏷 打标签。

  • 顶部会显示「按文件名猜出 N 个可能的标签」（自动建议，悬停能看到它是按哪段文件名猜的）；
  • 点 全部选中 一键采纳建议；
  • 同一维度里点多个 = 一次贴多个，但同一维度内每张素材只保留最后选中的那个；
  • 弹窗里有明确提示：已选维度上的旧标签会被这批新标签替换掉；
  • 右上角显示「已选 N 个标签」，底部按钮写着「贴到 N 个文件」—— 点下去才真正生效。
替换是设计如此同一个维度的旧标签会被清掉。比如某个文件原来标着「海报」，这次你只选了「折页」，那它就从「海报」变成「折页」，不会两个都留着。

4.6认领：把散文件收进任务

同事偷懒，直接把文件丢在工作区里、没进任何任务 —— 这类文件会全部进「未归属」池，不报错、不丢弃，等你认领。

两步认领

  1. 在文件视图（或点虚线「未归属」卡片跳过来）勾选要认领的文件。
  2. 在认领条上：[— 选择任务 —] 选目标任务 → 选子文件夹（01-成品 / 02-素材 / 03-工程）→ 点 确定认领。

「确定认领」= 把文件真实搬进目标任务的对应子文件夹（不是复制），并归属该任务。池子空了，虚线卡片自己消失。

4.7文件已丢失与重新定位

文件丢了 ≠ 记录没了。这是刻意的设计：原文件不在时，软件保留记录并打上「文件已丢失」标记，标签和版本信息一个都不丢。

单条找回

在丢失那一行点行尾的 🔍 重新定位，指到文件现在的位置。接受条件很严格，防止找错文件：文件名 + 扩展名 + 大小三者全对才算匹配。

批量找回

  1. 文件视图工具栏 → 批量重新定位（有丢失时才出现）。
  2. 点「选择文件夹」指向它们现在所在的文件夹。
  3. 软件按原目录结构逐层试配 → 你先看结果、勾选之后才会改记录。

挪到工作区内已登记过的位置时，会自动合并重复记录（标签转挂，不丢）。

忽略与清记录

动作说明
忽略丢失选中的文件不打算找回了 → 忽略后不再提醒，记录和标签都留着，随时能撤销
撤销忽略行尾的回转按钮 → 这条回到「文件已丢失」列表
清掉记录只删软件里的记录，不删任何文件（这些文件在磁盘上本来就已经不在了）。以后把文件放回原目录，扫描会重新建记录

统计口径

丢失的文件：条数算、容量不算。任务卡片上挂 ⚠ N，封面图会跳过丢失的文件。

四道门防误标不是随便就标丢失的。要同时满足：根目录读得到（移动硬盘插着）、文件真的不在、项目没被解绑、所属包文件夹还在 —— 才打标记。拔了移动硬盘不会造成一片假丢失。

视频没缩略图？检查 安装目录\resources\ffmpeg\ 下是否有 ffmpeg.exe（随包分发）。缺失时图片仍正常，只有视频功能降级。

6.3边界：限制清单

#限制具体表现
1软件没有「删除」功能界面里找不到「删除素材 / 删除任务」按钮。想删文件请去资源管理器；想删任务就删任务文件夹再刷新扫描
2文件丢失 ≠ 记录消失原文件被删 / 挪走 → 记录保留并标「文件已丢失」，可重新定位
3同一时刻只有一个「当前工作区」多库可切换，但同时只用其中一个；切库会清空筛选状态
4跨盘搬移工作区要手工软件只做同盘瞬时搬移，跨盘弹窗教你自己复制
5版本文件夹只认 V<数字>手工建的 V1 / V2 会自动纳入；「终版」这种要手工「绑定」
6「物料类别」清单全局唯一建任务的类别选项 = 左栏标签里的物料类别；删 / 改会影响已有任务
7项目名不能以下划线或点开头会被拒绝（与软件自己的目录冲突）
8任务名里的非法字符会被净化见 3.3；建完可去资源管理器核对
9缩略图统一宽 320 px覆盖图片 / 视频 / PSD / PSB / PDF；其他类型只显示扩展名
10打包不包含丢失的文件已丢失的文件不进 zip，列表里也不显示
11关掉子表 ≠ 清空数据已同步进来的工单会留在本地，要手动清理（见 6.4 第 6 条）
12工单字段只读工单信息来自表格，软件里改不了（除本地三个字段）
13指派至少留一人接口无法清空成员列，要清空须去表格手动清
14统计口径任务卡片 / 状态栏的「文件数、容量」算全部版本，与「占硬盘多少」口径一致
15标签在同一维度内互斥批量打标签时，同一维度内每张素材只保留最后选中的那个
16文件必须放在任务文件夹结构里才归属任务丢在工作区任意位置的散文件只进「未归属」池，需要手动认领
17环境要求Windows 10 / 11 64 位；安装包未签名（会出现「已保护你的电脑」，选「更多信息 → 仍要运行」）；无显卡要求（软件主动关闭 GPU 加速）
18网络依赖素材管理完全离线可用；只有工单同步、指派写回、导出报表需要能访问企业微信

6.412 个「能干但别干」的动作

下面这些操作软件不会拦你（有的拦不了），但只要做了，就会遇到「记录对不上 / 东西找不到」的麻烦。每条都写清后果和正确做法。

#动作后果正确做法
1在资源管理器里改任务文件夹的名字刷新扫描后旧任务的记录 + 标签 + 版本关联被清理（留痕在 _system\backup\），新名字的文件夹变成「游离的包」出现在「待归类」用任务卡片 ✎「编辑任务信息」改名 —— 软件会改名并保住全部关联
2把任务文件夹挪到别处同上：记录被清理 / 标丢失，标签、版本、工单关联全丢用「编辑任务信息」改项目（软件搬文件夹）；换盘用工作区搬移
3把文件直接丢在工作区根目录会进「未归属」池，不属于任何任务 / 版本，统计口径混乱丢进 任务\V1\01-成品（或对应组）再刷新扫描；或丢进去后「认领」
4手工改名 V1 / V2 文件夹（如改成「第一稿」）这一稿在版本条上显示「文件夹不在」，文件可能掉进「未分版本」保持 V<n> 命名；想用别的名字就「绑定文件夹」
5删 _system 文件夹（尤其 media.db）所有标签、版本记录、工单记录、本地字段全部丢失；素材文件还在，但会变成待归类 / 未归属，需要重新整理备份 / 搬移请整目录复制，别单独动 _system
6关掉子表后不做清理关闭只停止「以后同步」，已同步进来的工单会永久留在本地工单设置 → 危险操作区 →「清理这些工单」（会先预览条数、二次确认、删除前自动备份到 _system\backup\）。已建任务包的工单会被跳过不删
7用网盘 / OneDrive 同步目录当工作区云端占位符、改名、并发写会让大批文件被判「文件已丢失」，甚至数据库损坏工作区放在本机固定盘或移动硬盘，不要放在自动同步目录里
8两台电脑同时打开同一个工作区（共享盘 / 网络位置）数据库是单机独占的，并发写有损坏风险；两边操作也会互相覆盖一个库同一时间只在一台机器上用；跨机用「复制工作区 + 添加工作区」
9把「解绑项目」当「删除」用项目在软件里彻底隐身，容易误以为文件没了（其实在 _已解绑的项目 里）结项留底用它；只是想清理视图也可以，但要知道东西还在，随时可「还原」
10删进回收站后，再去资源管理器删 _回收站这是唯一能真正彻底删除素材的路径，删了不可恢复确认一个季度内都不需要了再删
11在智能表格里改列名 / 删列 / 删行删行 → 软件标「已不在表中」留底（不删记录）；改列名 → 对应字段读不进来，会出警告；删「设计师」列 → 指派不可用改结构前先在软件里同步一次留存基线；改完再同步看警告
12软件正在跑扫描 / 同步时，直接拔移动硬盘或强退工作区变成「连不上」，需要「重试」；极端情况下会留下半成品临时文件等操作结束；非正常退出后先「重试」，再「刷新 / 扫描」
补充一条「合法但容易忘」在软件里把某稿「解绑」之后，下次扫描不会又把它自动认回来（软件记了忽略名单）。想收回就在版本条上点「绑定」—— 所以解绑是安全的，不怕手抖。

6.5常见问题 FAQ

双击图标没反应 / 一闪就没了？

① 先等 10 秒（首次启动要初始化工作区）；② 若弹出「启动 / 运行异常」黑框，把里面的内容截图发给管理员；③ 检查是不是杀毒软件拦了 —— 把安装目录加进白名单。

顶部出现黄条「工作区『xxx』连不上，里面的东西一件没动」？

说明工作区所在的盘没挂上 / 没权限。插好移动硬盘后点 重试；路径变了就点 更改位置 指到新位置。软件绝不会偷偷换位置。

我把文件放进文件夹了，软件里怎么没有？

软件不会自动发现。回软件点 刷新/扫描。如果还是没有：① 确认文件放在 任务文件夹\V几\01-成品|02-素材|03-工程 里；② 检查左栏筛选是不是选了某个标签 / 项目把结果过滤掉了。

文件行显示「⚠ 文件已丢失」怎么办？

说明记录还在、磁盘上的原文件找不到了。点行尾 🔍 重新定位 指到它现在的位置（校验：文件名 + 扩展名 + 大小全对才接受）；一批文件同时被挪走就用工具栏 批量重新定位。

为什么工单同步提示「企微同步暂不可用」？

两种可能：① 没授权（最常见）—— 界面会直接弹出授权引导，用手机企业微信扫一次就好；② 内置组件缺失（安装包不完整，少见）—— 换最新安装包重装一次。两种情况都不影响素材管理、任务、打包这些功能。

换了电脑 / 换了 Windows 登录账号，要做什么？

重新扫码授权一次（首次启动会自动弹引导）。授权凭据存在 Windows 用户目录里，换软件版本、重装软件都不用重扫。

同步了，但我的单没自动建任务？

按 2.10 的五个条件逐条看。最常见是 「业务归属」和软件里的项目名不一致 —— 把两边名字改成一样，下轮同步会自动补建；也可以打开工单详情点「建任务」手动补。

「异常」筛选里出现的单是什么意思？

① 编号在表里出现两行（撞号）→ 去表格修正；② 业务归属的项目在软件里不存在 → 对齐项目名。

我的单没出现在导出报表里？

先看这张单的完成时间是不是空的 —— 审批还没走完的单，完成时间是空的，天然不进报表。再看选的起止日期区间有没有覆盖它。另外「已不在表中」的留底单也不进报表。

点「完成任务」报错？

「该任务未关联工单」→ 这个任务不是从工单建的，没有可回写的单；「未找到成品图」→ 先往任务的 01-成品 放一张成品图（图片），刷新扫描后再点；上传 / 写回失败 → 多为网络或权限问题，稍后重试，不影响任何已有数据。

为什么「关闭子表」之后工单还在？

关闭子表只停止以后的同步，不会删历史数据。用「工单同步设置 → 危险操作 → 清理这些工单」（已建任务包的会跳过）。

视频没有缩略图？

检查 安装目录\resources\ffmpeg\ 下是否有 ffmpeg.exe（随包分发）。缺失时图片仍正常，只有视频功能降级。

界面字太小 / 左栏太窄？

左栏宽度：拖分隔条，双击复位。界面整体缩放请用系统的显示缩放设置。

软件里的数量统计和资源管理器里数出来的不一样？

正常。软件统计的是登记在库里的记录：_thumbs / _system / _回收站 等下划线开头的目录一律不统计；「文件数、容量」算全部版本。

能多人同时用吗？

每人一台电脑、各自一个工作区，各自独立使用。需要共享素材就把整个工作区文件夹复制给对方（或放到共享盘让对方「添加工作区」，但不要两边同时打开写）。
