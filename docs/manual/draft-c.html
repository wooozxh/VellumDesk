2.2任务详情与版本管理

点任意任务卡片打开。这一屏是日常干活停留最久的地方。

顶部按钮逐个说

按钮作用影响磁盘？
✎ 编辑任务信息改名称、所属项目、类别改名 / 改项目会；只改类别不会
📁 打开文件夹资源管理器打开任务文件夹不会
🔗 快捷方式桌面 + 开始菜单各建一个快捷方式只在桌面/开始菜单建 .lnk
📦 打包交付按版本 / 分组打成 zip只新增一个 zip
✓ 完成任务成品缩略图写回工单队列不会

用「快捷方式」的三步

  1. 任务详情 → 点 快捷方式；
  2. 桌面和开始菜单各出现一个图标，双击直接进任务文件夹；
  3. 同名已存在 → 弹确认；文件夹不在 → 提示，不建死链。
NOTE任务改名不会自动更新旧快捷方式 —— 改名后重新点一次即可。软件不会去翻你的桌面。
GOTCHA任务文件夹在磁盘上被删/被挪走后，按钮会提示「任务文件夹不在了」。先在顶栏点「刷新/扫描」确认任务还在。

1.1四层结构

整个软件只有四个概念，理清它们就能看懂任何一个界面。

工单负责什么
起头（自动建空任务）与回写（成品缩略图）。
任务负责什么
放文件、改稿、打包交付 —— 所有体力活。
