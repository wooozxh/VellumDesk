# Vellum工作台 v1.14.0 更新说明

> 上一版：v1.13.0（2026-11-01）　→　本版：v1.14.0（2026-11-10）
>
> 一句话：**关窗不再退出**（收进右下角托盘），**被派单会弹系统通知**；设置里两个「后续版本」的占位变成了真开关。

---

## 一、关闭窗口 = 收进托盘

点右上角的 X，软件不再退出，而是**收进右下角托盘**继续在后台跑 —— 自动同步和你被派单的提醒不会因为"顺手关了窗口"就停掉。

托盘图标右键：

| 菜单项 | 作用 |
|---|---|
| 打开主界面 | 把窗口叫回来（左键单击图标也行；窗口在前台时单击是收起） |
| 刷新数据 | 等同于顶栏的刷新按钮 |
| 同步工单 | 立刻跑一轮同步，跑完弹一条结果通知 |
| 设置 | 叫出窗口并直接打开设置 |
| 退出 | **真正退出**，自动同步随之停止 |

第一次收进托盘会弹一条提示，告诉你它去哪儿了。

## 二、被派单会弹系统通知

自动同步跑到**新派给你**的单（「设计师」列里有你，或者设计师列空着、审批意见里 @ 了你），建完任务会在右下角弹一条系统通知：

- 标题：`收到 1 个新工单` / `收到 3 个新工单`
- 正文：任务名（最多两个，再多显示「等 N 个」）
- **点通知直接打开软件**

窗口就在前台时不弹（列表已经自己刷过了）；别人的单不弹。

## 三、设置里两个占位变成真的了

| 项 | 现在能做什么 |
|---|---|
| 列表密度 | **标准 / 紧凑**：紧凑把行高压到 30、卡片间距收一档，一屏多看三四行，字号和列宽不变 |
| 启动时打开 | 6 个选项：上次那一屏（默认）/ 工单队列 / 任务 / 文件 / 通用素材库 / 模板库 |

「关于」页也补上了 **打开手册** —— 手册随安装包装进软件目录，双击即看，不用再找管理员要文件。

## 四、审批意见里 @ 你，也算派单

提交时「设计师」列**空着**的单，审核人在审批意见里 @ 谁，谁的电脑上就会自动建任务，不用再点指派。

只认「@ + 姓名」：光是意见里出现名字不算（抄送、办理节点都会写名字）；**设计师列已经填了人时 @ 不生效** —— 那是转交或叮嘱，不是派单，软件不抢。

## 五、修：之前那些托盘气泡其实一直没显示

Windows 10 之后，旧的「托盘气泡」接口在多数机器上会被系统直接丢掉。这一版把三处提示（收进托盘、同步结果、新工单）全部换成**系统通知**，现在真的能看见了。

## 升级

| 项 | 说明 |
|---|---|
| 怎么升 | 下载 `VellumDesk-1.14.0-Setup.exe` 覆盖安装，不用先卸载 |
| 数据 | **一点不动**。素材、任务、工单、模板都在原来的工作区里 |
| 要注意 | Windows 提示「未知发布者」时点「更多信息 → 仍要运行」 |
| 手册 | 随包附 `VellumDesk-Manual-v1.14.0.html`（单文件，双击就能看）；设置 → 关于里也能打开随包安装的那一份 |
| 看不到通知 | Windows「设置 → 系统 → 通知」里确认本软件没被关；「专注助手 / 勿扰」也会压掉它 |
