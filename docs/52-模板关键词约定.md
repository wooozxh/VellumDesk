# 模板关键词约定（PSD Keywords → 软件读取）

> 生效版本：2026-10-17（第 69 批，`docs/51`）　｜　实现：`src/shared/tplInfo.ts` · `src/main/thumbs.ts`
>
> **一句话**：关键词是给 **PSD 里没有的信息** 用的。能读到的别写。

---

## 1. 先看：哪些根本不用写

下面这些软件**直接读 PSD 文件头**，写进关键词反而会和真实文件对不上：

| 信息                               | 来源            | 说明            |
| -------------------------------- | ------------- | ------------- |
| 画布像素（宽×高）                        | PSD 头         |               |
| 分辨率 ppi                          | PSD 图像资源 1005 |               |
| 色彩模式（CMYK / RGB / 灰度 / 位图 / Lab） | PSD 头         |               |
| 参考线条数                            | PSD 图像资源 1032 | 卡片右上角那个小标签    |
| 位深（8 / 16 / 32）                  | PSD 头         |               |
| 文件名、大小、修改时间                      | 磁盘            | 卡片大字（品类）从文件名取 |

> ⚠️ **不要写 `dpi:150`、`color:CMYK` 这种**：PSD 里改了分辨率而关键词忘了改，界面就会说谎。  
> 这类信息只有一个可信来源 —— 文件本身。

---

## 2. 要写的：成品尺寸 与 出血

PSD 里**没有**这两个标准字段，但它们决定了卡片上最重要的两个数字。

| 字段       | 可用的 key（英文 / 中文都认）            | 示例                | 单位                  |
| -------- | ----------------------------- | ----------------- | ------------------- |
| **成品尺寸** | `size` · `尺寸` · `成品尺寸` · `成品` | `size:80cm×180cm` | cm / mm / m（省略按 cm） |
| **出血**   | `bleed` · `出血`                | `bleed:5mm`       | mm（省略按 mm）          |

### 为什么尺寸要写、不能算

画布 = **成品 + 各边出血**。实测你的 `展架.psd`：

```
画布 4783×10689 @150ppi  =  80.99cm × 181.00cm
成品（你写的）            =  80cm   × 180cm
差                        =  各边 0.5cm = 5mm 出血
```

按画布算会显示 `81cm×181cm` —— 和你脑子里的"80×180 展架"对不上。

**不写也能用**：会自动按画布算，并在末尾带小数（如 `80.99cm×181cm`），一眼能看出"这是算的、不是标的"。

---

## 3. 可选字段（写了更好找，不写不影响）

| 字段          | 可用的 key                | 示例                   | 打算怎么用   |
| ----------- | ---------------------- | -------------------- | ------- |
| **用途**      | `usage` · `用途` · `场景`  | `usage:室内`           | 筛选、卡片提示 |
| **客户 / 品牌** | `client` · `客户` · `品牌` | `client:海南升学`        | 筛选      |
| **标签**（可多值） | `tag` · `标签`           | `tag:竖版` + `tag:双11` | 筛选      |
| **备注**      | `note` · `备注` · `说明`   | `note:2026 春季主推`     | 悬停提示    |

> 这几个字段**目前只进悬停提示**，还没做筛选 UI —— 但先把关约定下来，  
> 后面加筛选时这些模板不用返工。

材质 / 工艺（`material:KT板`、`finish:覆膜`）也能写，会被识别但暂不展示 —— 需要时再加。

---

## 4. 格式规则（容错优先，写歪了也不会坏）

用户是手写的，所以规则必须宽松：

| 规则      | 说明                                         |
| ------- | ------------------------------------------ |
| **分隔符** | `key:value` 最标准。也认全角冒号 `：`、等号 `=`、空格       |
| **大小写** | key 不区分大小写（`BLEED` / `Bleed` / `bleed` 一样） |
| **空格**  | key 前后、冒号两侧的空格都会被忽略                        |
| **单位**  | 尺寸省略 = cm，出血省略 = mm；`0.5cm` 会自动换算成 `5mm`   |
| **乘号**  | `×` `x` `X` `*` 都认（`80x180` = `80×180`）    |
| **多值**  | 同一个 key 可以写多次（`tag:竖版`、`tag:双11`），会全部收下    |
| **认不出** | 当作"自由备注"收着，**不报错、不影响卡片**                   |
| **写错**  | 完全不影响入库 —— 关键词只是"附加信息"，读不到就是没有             |

### 完整示例（一份展架模板该写什么）

```
size:80cm×180cm
bleed:5mm
usage:室内
client:海南升学
tag:竖版
tag:2026春季
note:主推款，画面上方留白给标题
```

中文写法同样生效：

```
成品尺寸：80cm×180cm
出血：5mm
用途：室内
客户：海南升学
```

## 5. 软件怎么读（可验证的处理顺序）

1. 打开 PSD → 扫图像资源段
2. **先读 IPTC（资源 1028，tag 25）**；没有再用 **XMP（资源 1060，`dc:subject`）** 兜底  
   （实测 XnView 两处都写；别的工具可能只写一处）
3. 每条按 `key : value` 拆解，按第 4 节的规则做归一化
4. 认得的字段填进卡片 / 提示；认不得的进"其他"
5. **同一个 key 出现多次**：最后一个生效（先写的被覆盖）—— 和"后写的更新"直觉一致

**什么时候重新读**：点「扫描磁盘」时。关键词改了不用删库重来，改完点一次扫描即可。

## 6. 写在哪（工具都行）

| 工具            | 位置                                                                  |
| ------------- | ------------------------------------------------------------------- |
| **Photoshop** | 文件 → 文件简介（File Info）→ 关键词                                           |
| **XnView MP** | 元数据 / 编辑 IPTC-IIM → Keywords（已实测可用）                                 |
| **ExifTool**  | `exiftool -Keywords="size:80cm×180cm" -Keywords="bleed:5mm" 文件.psd` |
| **Bridge**    | 文件信息面板 → 关键词                                                        |

> ⚠️ 第三方工具改元数据会**重写整个 PSD**，第一次用建议先拿副本试一下，  
> 确认图层、智能对象都还在。

## 7. 现在的实现边界

| 项                                      | 状态                                                              |
| -------------------------------------- | --------------------------------------------------------------- |
| 读 IPTC + XMP                           | ✅                                                               |
| `size` / `bleed` 进卡片                   | ✅                                                               |

| 按关键词筛选模板                               | ⏳ 未做（先定约定，再上 UI）                                                |
| **从参考线自动推断出血**                         | ⏳ 未做 —— 技术上可行（读参考线坐标，看是否内缩等距），但参考线也可能是栏间距/安全区，**误判比不判更糟**，所以先不做 |
| 读图层数 / 智能对象 / 图层名                      | ⏳ 未做（要解析图层段，成本高、收益低）                                            |
