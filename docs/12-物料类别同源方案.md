# 12 · 物料类别同源方案（第 10 批）

> 状态：✅ 已完成（2026-09-30）。用户实测报的 bug，当天修完：619 项断言 + `category` 界面场景全过。

## §0 一句话

**建包 / 编辑包时能选的「物料类别」，就是左栏筛选里那一套** —— 全软件只有这一份清单，增删改都在左栏「标签管理 → 物料类别」里做，改了当场生效，改名 / 删除还会反向联动到已有的包。

## §1 为什么改（bug 的来历）

用户实测发现：新建包弹窗里的「物料类别」和左栏筛选标签里的「物料类别」对不上。

| | 来源 | 内容 | 能否维护 |
|---|---|---|---|
| 左栏筛选 | 数据库 `tags` 表（`dimension='category'`） | 海报、折页、详情长图、短视频、宣传片、直播物料、字体、图标素材、参考图（9 项） | 能（第 3 批标签管理） |
| 建包 / 编辑包 | `db.ts` 写死的常量 `CATEGORIES` | 海报、视频、折页、推文配图、PPT、其他（6 项） | 不能 |

两套只有「海报、折页」重叠。`db.ts` 里那行注释是第 1 批埋的欠条：

```ts
/** 物料类别：暂仍为固定项（标签专项时再改成可维护） */
```

第 3 批做标签体系时没回头还账，于是同一个词「物料类别」在软件里是两套数据。

## §2 用户拍板（2026-09-30）

1. **修法选 A（清单统一）**，不选 B（`packs.category` 改存标签 id 外键）—— A 不动表结构，改名用一条 UPDATE 跟随，回归面小
2. **删除类别的交互（用户原话定的）**：
   > 提示"目前有 X 个包正在使用此标签，删除后这些包所带的标签也会被删除，是否确认删除？"，点击确认后，使用这个标签的包中的这个标签也会被去掉。

   落地时"去掉"归到「未分类」—— 包必须有类别，空串在界面上是说不清的状态。

## §3 行为清单

| 场景 | 行为 |
|---|---|
| 左栏加一个类别 | 建包 / 编辑包弹窗**当场**多一项（渲染层从 `tagDimensions` 派生，标签 reload 即生效） |
| 类别标签改名 | `packs.category` 在**同一事务**里跟着改（`updateTag` 返回 `packsUpdated`）；改名失败回滚，不会出现"标签改了包没改" |
| 删除类别标签 | `tagUsage` 先报 `packCount`，确认弹窗红字提示「目前有 N 个包正在使用这个类别…」；确认后这些包归「未分类」（`removeTag` 返回 `packsAffected`） |
| 渠道 / 状态维度 | 跟包**无关**：就算撞了同名标签（跨维度允许同名），改 / 删 `packsAffected` 恒为 0 |
| 解绑项目名下的包 | 照样联动（界面上隐身 ≠ 数据冻结，重新绑定回来类别还得是对的） |
| 类别被删光 | 建包弹窗给指引文案，仍可建包（记「未分类」） |
| 扫描 | 不重置包的类别；手工建的包文件夹被扫进来记「未分类」 |
| 老数据兜底 | 编辑包弹窗里当前类别不在清单时补在第一格（`EditPackModal` 原有容错保留） |

## §6 明确不做

- `packs.category` 不改外键（方案 B 被否：动表结构 + 迁移，回归面大）
- 删类别**不**提示逐包确认、只报总数（用户原话就是一条总数提示）
- 删除标签不"顺带改素材"以外的任何东西（素材文件、版本记录都不碰）
- 不做"建包时选的类别自动给包内文件打标签"（隐性动作，没人要求）
