# Vellum工作台 v1.13.0 更新说明

> 上一版：v1.11.0（2026-10-17）　→　本版：v1.13.0（2026-11-01）
>
> **这一份把原计划的 v1.12.0 一起算进来了。** v1.12.0 只有「浅色主题 + 四个小修」，隔了两天界面又整体换了套视觉，
> 所以撤掉了那个包、合成一次发 —— 你现在装的这一版，等于 v1.12.0 + 这次的界面改版，不会有任何东西漏掉。
>
> 一句话：**界面统一了一套视觉规范（颜色 / 圆角 / 间距 / 表格密度），配置入口收进「设置」，外加浅色主题和四个修复。**

---

## 一、界面换了套视觉（这次最大的变化）

不是换肤，是**立规范**。之前同一个软件里并存着 3 套按钮高度、4 种标签样式、3 档弱化灰，看着"哪儿都对不齐"。这回全部收敛成一套：

| 项目 | 现在 |
|---|---|
| 配色 | 深色是中性灰（不带蓝调），主色是一档蓝，选中态统一成「浅蓝底 + 蓝字」 |
| 圆角 | 按钮 / 输入框 6 px、标签 4 px、卡片 10 px、弹窗 14 px —— 之前那种"全圆胶囊"只留给了圆点和开关 |
| 表格 | 行高 34 px、表头 32 px；编号和日期**右对齐**且数字等宽（一列数字终于是能比大小了） |
| 卡片 | 封面压到 104 px，标题最多两行（长短标题的卡片**一样高**，网格不会参差） |
| 提示条 | 从"底部居中"挪到**右下角**，不再压住表格最后一行 |

功能没变，只是看起来"像一件事"了。

## 二、新增：「设置」窗口（顶栏齿轮）

原来"插件联动""企业微信授权""工单同步设置"散在**三个地方**（顶栏一个按钮、工单视图一个齿轮、首次向导一页）。它们都是**配一次、一年不再点**的东西，却占着顶栏最贵的位置。

现在统一收进顶栏最右的**齿轮**，五个页签：

| 页 | 管什么 |
|---|---|
| 通用 | 界面主题（深色 / 浅色） |
| 工作区 | 素材目录在哪、打开文件夹、换位置 |
| 企业微信连接 | 扫码授权（工单同步用的） |
| PS 插件联动 | 模板目录与自动同步开关 |
| 关于 | 版本号、手册位置 |

**改了就生效，没有「保存」按钮。** 顶栏原来那个「插件」按钮已经没了 —— 去齿轮里找。

## 三、新增：浅色主题

顶栏最右的圆钮，点一下在**深色 / 浅色**之间切换。

| 按钮上画的 | 意思是 |
|---|---|
| ☀ 太阳 | 现在是深色，**点它变浅色** |
| ☾ 月亮 | 现在是浅色，**点它变深色** |

- **切完会记住**，下次打开还是那个模式。
- 浅色不是纯白：底是暖纸色，面板和卡片一层比一层亮一点点，长时间看不刺眼。
- 深色仍是默认，习惯深色的同事不用管它。

## 四、顶栏和工具条重新分了层

顶栏只管「换到哪一屏」，视图自己的动作回到视图里：

- **「＋ 新建任务」「备份打包」「卡片 / 列表切换」** —— 从顶栏下移到**任务视图内容区顶上那条工具条**（左边「任务 N 个」，右边三个动作）。文件视图、模板库各自的主按钮也同样在自己的工具条上。
- **左栏可以整栏收起** —— 顶栏最左那个按钮，点一下收起、再点恢复。看大图、对长文件名时腾地方用。
- **工单队列 / 通用库 / 模板**这三个视图自己带目录树，没有"收起左栏"这回事，那个位置现在显示**软件 logo**。
- 顶栏换视图时**一个控件都不会左右跳**了（原来搜索框会时有时无，页签整体平移）。

## 五、修：工单同步设置里那个按钮"跑出去了"

设置窗口 460 px 宽，那一行塞了「标题 + 状态 + 来源 + 两个按钮」，最右边那个按钮被顶到框外，旁边那行来源还被挤成**一个字**（"环"）。

现在：那一行改成**左边两行（标题 + 状态 / 来源）、右边两个按钮**；长按钮名从「重新打开配置向导」缩成「**配置向导**」。两个按钮都在框内，来源也能完整读到（例如 `环境变量 · v1.2.1`）。

## 六、修：设置弹窗的「保存」按钮点不到

**现象**：首次配置引导里填完工单链接，或者打开「工单同步设置」，弹框里的说明文字一多，**保存 / 取消就被挤到屏幕外面**，只能按 Esc 关掉。

**现在**：弹框内容多的时候**自己滚动**，保存 / 取消**固定在弹框底部**。同一个毛病一并修好的还有**导出报表**、**插件联动设置**。

## 七、修：那个「小太阳」其实该是齿轮

工单队列里，「导出报表」旁边那个按钮（工单同步设置）原来的图标画得像颗太阳，十几个同事都以为是"主题切换"。已换成正经齿轮。

## 八、修：素材库里冒出 `._` 开头的怪文件

**现象**：从 Mac 拷过来的素材文件夹，素材墙里会多出一堆 `._IMG_0001.jpg`、`.DS_Store` 之类的条目，看着像素材、点开是坏的。

**现在**：这类文件**不再进素材库**（扫描时跳过，磁盘上一个字节都不动）；库里已经混进去的，这次扫描会自动清掉记录；删组时如果目录里只剩这类文件，也能正常删掉了。

## 九、升级

| 项 | 说明 |
|---|---|
| 怎么升 | 下载 `VellumDesk-1.13.0-Setup.exe` 直接装，覆盖安装即可 |
| 数据 | **一点不动**。素材、任务、工单、模板都在你原来的工作区里 |
| 从 v1.12.0 升上来 | 不用先卸，直接装这一版就行；那个包已经撤了 |
| 要注意 | 如果 Windows 提示"未知发布者"，点「更多信息 → 仍要运行」 |
| 手册 | 随包附 `VellumDesk-Manual-v1.13.0.html`（单文件，双击就能看） |

## 十、已知限制

- **手册里的截图还是上一版界面**（顶栏按钮位置有变化）：这一轮样式改得太广，52 张图没法一次全重拍。**操作以文字说明为准**，下一版统一重拍。
- 浅色模式下同样沿用旧截图，看截图时留意配色差异。
- 主题是**每台机器各自记**的，不跟着工作区走 —— 换电脑需要重新点一次。
- 「列表密度」「启动时打开」两项目前是占位，标着「后续版本」。
- 老问题仍在：模板库不能按 usage / 客户 / 标签筛选；导出 PNG 尚未支持。
